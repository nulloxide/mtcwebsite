# Monachil Technologies

Corporate website for [Monachil Technologies](https://monachiltech.com), the technology division of Monachil Capital Partners LP.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build & Deploy

```bash
npm run build
```

Deploys automatically to GitHub Pages on push to `main`.
